# проверка веб-интерфейса карты

запускать из корня проекта. нужны python 3, node.js, playwright и установленный chromium. при необходимости путь к браузеру задаётся через PLAYWRIGHT_EXECUTABLE_PATH.

```bash
python3 tests/browser/service-gateway.py
```

в другом терминале:

```bash
node tests/browser/visual-regression.cjs
```

gateway используется только для тестовой среды: получает реальные публичные тайлы и ответ пешего сервиса через проверенный https, затем передаёт их браузеру без изменения тела и cors-заголовка. разрешены только домены tile.openstreetmap.org и routing.openstreetmap.de. в приложение этот gateway не включается. обход проверки сертификатов не используется.

координаты в тесте публичные и заданы явно; местоположение пользователя не запрашивается. тест проверяет обычный leaflet, действительный маршрут, обе темы, поиск, выбор аудитории нажатием, перетаскивание, клавиатуру, узкие экраны и уменьшенное движение. json-результаты и локальные снимки создаются в verification/0.6.0 рядом с проектом. эти снимки не включены в поставляемый архив.
